# Graph Schema

所有节点仅有属性：
- name: 实体名称（主要查询字段）

## Node Labels

药材、方剂、病症、症状、证候、靶标、
Canonical_smiles、Inchikey、西医病症、
典籍、人体部位、症状详情、病症详情、证候详情


## Relationships

药材 -[组成]-> 方剂

方剂 -[主治症状]-> 病症
方剂 -[主治症状]-> 症状
方剂 -[主治证候]-> 证候
方剂 -[来源于]-> 典籍

药材 -[治疗]-> 症状
药材 -[HAS_Canonical_smiles]-> Canonical_smiles
药材 -[HAS_INCHIKEY]-> Inchikey

病症 -[病因]-> 证候
症状 -[病因]-> 证候

证候 -[表象]-> 病症
证候 -[表象]-> 症状

病症 -[对应西医病症]-> 西医病症

症状 -[病因所在部位]-> 人体部位

症状 -[症状详情]-> 症状详情
病症 -[病症详情]-> 病症详情
证候 -[证候详情]-> 证候详情

Canonical_smiles -[靶标基因为]-> 靶标
Inchikey -[靶标基因为]-> 靶标

关系有存储方向，查询时可以根据问题需要反向遍历；回答时按关系语义解释，不要把反向查询理解成反向关系。
